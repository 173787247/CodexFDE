# Codex AI 工程交付行动营｜讲义阅读导航

课程先用 Codex 建设个人研发工作台，再通过工作台组织人与 Codex 协同，持续开发 FlowERP。最终交付的是这套能够继续接收需求的系统，包括可复用工作台与有交付记录的客户产品。

讲义面向具有高等教育背景、软件工程经验各异的学习者。每讲从一个具体问题推导机制，在首次使用时解释必要术语，并讨论结论的适用范围。代码和命令用于支撑理解；课后通过自己的实现与复验检验判断。

## 阅读之后怎样动手

L01 的操作手册、提交模板和工具集中在 [L01 目录](./L01/README.md)。其余每讲正文末尾连接行动卡、实践提示词和提交模板：讲义解释设计与判断，行动卡给出隔离工作区与执行步骤，模板索引你实际产生的结果。

开始操作前先完成 [L00 环境准备](./L00-课前准备-安装工具与通过环境自检.md)。参考仓库的当前成功结果用于理解目标；自己的建设过程需要从约定起点出发，保留实现前问题、修改与复验。

每讲附录保留大纲的核心内容、演示结果、课内增量与通过标准，完成后可以逐项核对。[课堂 PPT](./slides/README.md)用于演示与讲解；完整推导以本导航连接的阅读讲义为准。
