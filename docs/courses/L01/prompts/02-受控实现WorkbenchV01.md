# 交互 2｜受控实现 Workbench V0.1

请先读取仓库根目录的 `AGENTS.md`、已签署的 `docs/courses/L01/WORKBENCH_SPEC.md` 和本文件。

目标：在隔离教学工作区实现一条最小闭环，使工作台能够初始化自身、登记项目、创建任务、保存命令证据并检查状态完整性。

执行顺序：

1. 把 Spec 验收项映射为正常路径、失败路径和测试名；
2. 先只生成测试，向我解释输入、操作、比较和失败后状态，等待我核对并亲自按讲义保存有效红灯；保留命令、输出、退出码与带时区观察时间，此时不实现工作台；
3. 给出最小实现计划和预计修改文件，等待我授权；
4. 获得授权后实现，说明每项实现对应哪项设计理由，并保留实际 Diff；不得删断言、跳过用例或放宽验收制造绿灯；
5. 不做最终签收，把结果留给下一次交互复验。

边界：只修改 Spec 声明的工作台源码与 L01 测试；不修改 FlowERP、ERP 页面或业务数据库；不联网、不安装、不扩展 Web、API 或多 Agent。需要扩权、验收口径不明确或数据边界未知时立即停止。完成后停下，把签收留给交互 3。
