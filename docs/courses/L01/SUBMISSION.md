# L01 提交模板

【课后动手实践】

将本文件复制到隔离区 `lesson-01-submission/SUBMISSION.md` 作为总索引。下方每个“保存为”小节都是可直接填写的文件内容；按标注另存为对应文件。保留首次判断，修订写到后续文件。原始证据由采集工具生成，不手写退出码、时间或成功结果。

## 提交索引与检查

- [ ] `00-isolation.json`：真实创建结果，隔离路径与起点已核对。
- [ ] 下方 10 份个人材料已填写；Spec 在 `docs/courses/L01/WORKBENCH_SPEC.md`，已本人签署。
- [ ] `03-failure/`：保留每次输出、元数据；有效红灯旁另存 `reason.md`，解释失败对应哪项要求。
- [ ] `04-diff/`、`05-green/`：保留实际改动与每次复验（包括失败）。
- [ ] `06-observations/`：保留全量状态、导入前后、错误任务、恢复查询的观察。
- [ ] 文件路径在下方索引可查，同命令红—Diff—绿时间严格递增。
- [ ] 已取得真实反馈或标明待复核；没有代签，没有用参考结果替代本人证据。

个人材料与运行数据库不提交 Git；按课程指定渠道交付代码、Spec 和必要证据，数据库留在本地。完整步骤见[实践操作手册](./实践操作手册.md)。
