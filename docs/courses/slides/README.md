# Codex AI 工程交付行动营｜L01～L16 独立课件

这 16 份课件逐讲对应极客时间课表的“主题”原文，并服从课程大纲规定的核心内容、演示结果、课内增量和通过标准。

> **工作台是主体，FlowERP 是验证场，Codex 是底座。**

每份课件均为 16:9、22 页、约 30 分钟的独立课堂版本，包含真实冲突、第一次判断、机制、仓库代码、正常路径、失败路径、失败后状态、迁移判断和任务卡交接。图表和三层关系图使用可编辑的 PowerPoint 原生对象；讲者备注列出当讲边界、讲义入口和已核验的一手来源。

## 使用边界

- 课件负责 30 分钟问题框架、核心机制和关键示范；学生的失败实验、修订、互评和迁移在讲义、任务卡与实验目录完成。
- 截图只用于定位界面，不能代替命令、退出码、权威状态和具名复验。
- L04 完成 Workbench V0 的自举换挡；L16 必须现场交付此前未实现、范围受控的 FlowERP 小需求，不能用历史演示冒充。
- Codex、GitHub Actions、HTTP、WCAG 等易变资料的核验日期见各讲讲者备注和讲义正文。
