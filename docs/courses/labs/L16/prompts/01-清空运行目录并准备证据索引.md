# 交互 1｜清空运行目录并准备证据索引

请先读取 `AGENTS.md`、16 讲合同和本文件。先确认基线，再创建新的独立运行目录，保留旧任务与失败证据。

贯穿案例：结业要由工作台现场交付一个此前未实现、范围受控的 ERP 小需求。作者自己电脑上的熟练演示不是冷启动。

执行顺序：

1. 准备证据清单：需求、Diff、Eval、人审、剩余风险。任务建立后用 `course-release-index` 生成索引草稿，缺项保持缺失，不填写虚构材料；
2. 使用新的独立运行目录，避免带着旧库演示，同时保留旧记录；
3. 现在不要抽已经实现的功能，不要开始编码。

命令和文件要求见 `docs/reference/发布证据索引.md`。生成索引不会批准任务；成功退出只说明索引生成成功。
