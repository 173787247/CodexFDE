# 打开个人工作台

完成 L00 项目环境准备后，在项目根目录双击 `打开工作台.cmd`。浏览器会打开个人工作台，默认地址是 `http://127.0.0.1:8001`。

关闭浏览器不会删除任务，也不会结束后台工作台；再次双击会重新打开同一份工作台，不另建一套任务数据。任务保存在项目的 `.runtime` 目录，请保留该目录。启动失败时会提示日志位置；不要删除日志后反复重试。

该入口开放网页执行方案。选择“让 Codex 实现”后，仍需选择讲次、核对范围并明确授权；打开页面本身不执行代码修改。检查通过后仍须具名验收。L01～L03 先由学生直接监督 Codex 建造能力，不能用终态工作台代替自己的构造证据。

若提示项目环境缺失，先完成 L00 安装。若提示端口被另一份服务使用，核对原来的工作台与项目目录；启动器不会终止其他程序或把其他目录的数据当作当前任务。

同一个入口也会检查并启动 FlowERP 客户项目（默认 `http://127.0.0.1:8000`），不需要另外输入启动命令。两者分别保存到 `.runtime/workbench.db` 和 `.runtime/flowerp.db`；重新打开不会清空数据或自动装入样例数据。只有确认属于当前数据目录的服务才会被复用。

如果客户项目启动失败，工作台仍会打开，启动窗口会提示具体原因并保留日志。处理原因后再次双击，可补启动缺失的服务。不要把“服务启动成功”当作“交付完成”：还需核对产品页面、代码执行、复验和人审结果。

异常退出后立即重开时，可能出现“正在等待上次运行释放数据”。保持窗口打开即可，启动器最多等待 35 秒后继续启动；不用连续点击。如果等待后仍提示另一个实例使用数据，请核对其他 FlowERP 窗口，启动器不会抢占或删除原数据。

授权后关闭或刷新页面，再打开时可用“找回上次交付”查看原执行进度。该按钮只读原记录，不会再次授权。若提示工作台已重启，先检查已创建的任务和失败原因；不要把原方案中断理解成可以直接重复提交。执行方案与任务关联保存在工作台数据库中，浏览器只记住待查询的方案编号。

L13 目前默认采用“工作台任务受理修订版（2026-09-05）”。只需选择讲次并查看方案，不必填写版本编号。该材料已有维护演练证据；学生仍须亲自完成构造和验收。课程源码与 `course/session/l13-20260905` 标签必须配套提供，缺失时页面会提示更新材料，不会退回不匹配的旧版。其他讲次的材料仍需完成成品验收。
